# RoomFlow · Entrada STRUTS

Aplicación Java 8 de reservas de salas para el wizard UI Modernization. Incluye listado, búsqueda, alta, detalle, confirmación y cancelación. Los datos se guardan en memoria y se restauran al reiniciar.

Arranque local: `mvn clean package` y `mvn jetty:run`.

Entrada: `http://localhost:8085/roomflow/reservations.action`.

El proyecto utiliza dependencias antiguas como material del laboratorio. El servidor escucha en localhost. La guía del participante es [LAB.md](../LAB.md).
